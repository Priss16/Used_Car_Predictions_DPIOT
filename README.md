# 🚗 AutoLuxe AI – Used Car Price Prediction & Analytics

AutoLuxe AI is a web-based **Used Car Price Prediction and Analytics** project.

The system uses **Machine Learning** to predict the price of a used car based on its details. It also provides interactive charts using **Plotly**, stores prediction results in **Firebase**, and sends the predicted price to **Node-RED using MQTT** for real-time visualization.

---

## 📌 Features

* Used car price prediction
* Random Forest Machine Learning model
* Flask web application
* Interactive Plotly charts
* Firebase database integration
* MQTT communication
* Mosquitto MQTT broker
* Node-RED dashboard
* Real-time predicted price display

## 📄 Main Files

### `01_test_data.py`

Checks and verifies the original dataset.

### `02_eda.py`

Performs Exploratory Data Analysis to understand the dataset.

### `03_preprocessing.py`

Cleans the data, removes duplicates and handles missing values.

Creates:

```text
dataset/cleaned_used_cars.csv
```

### `04_ml_model.py`

Trains the Random Forest Machine Learning model and saves it as:

```text
used_car_price_model.pkl
```

### `05_visualization.py`

Creates interactive Plotly charts for car price analysis.

### `app.py`

The main Flask backend.

It:

* Loads the trained model
* Receives car details from the website
* Predicts the car price
* Stores the prediction in Firebase
* Publishes the prediction using MQTT

### `templates/index.html`

Contains the main website interface where the user enters car details and views the prediction and analytics.

# 🤖 Machine Learning

The project uses a **Random Forest Regressor** for predicting used car prices.

The model uses features such as:

* Manufacturing year
* Kilometers driven
* Fuel type
* City
* Body type
* Transmission
* Make
* Model
* Number of owners
* Car rating
* Warranty availability

The target variable is:

```text
sale_price
```

The trained model is stored in:

```text
used_car_price_model.pkl
```

# ☁️ Firebase

Firebase is used to store the predictions generated by the application.

The flow is:

```text
User
  ↓
Flask
  ↓
Machine Learning Model
  ↓
Predicted Price
  ↓
Firebase
```

Each prediction can be stored for future reference.

> Firebase service-account credentials should not be uploaded to GitHub.

# 📡 Node-RED + MQTT

Node-RED is used to display the predicted car price in real time.

MQTT is used for communication between the Flask application and Node-RED.

### Communication Flow

```text
Flask
  ↓
MQTT Publish
  ↓
Mosquitto Broker
  ↓
MQTT Subscribe
  ↓
Node-RED
  ↓
Function
  ↓
Gauge
```

### MQTT Topic

```text
car/prediction/price
```

### MQTT Broker

```text
localhost:1883
```

### Node-RED Dashboard

```text
http://localhost:1880/ui
```

The dashboard contains a **Predicted Car Price Gauge**.

# ⚙️ Installation

## 1. Clone the Project

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd Used_Car_Predictions
```

## 2. Create Virtual Environment

```bash
python -m venv venv
```

Activate it in PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

## 3. Install Python Packages

```bash
pip install -r requirements.txt
```

---

# ▶️ How to Run

The project uses **three main components**.

## 1. Start Mosquitto

If Mosquitto is not already running:

```powershell
mosquitto -v
```

MQTT uses:

```text
localhost:1883
```

If you see:

```text
Error: Only one usage of each socket address...
```

it usually means Mosquitto is already running on port `1883`.

---

## 2. Start Node-RED

Open another terminal:

```powershell
node-red
```

Open Node-RED:

```text
http://localhost:1880
```

Open the dashboard:

```text
http://localhost:1880/ui
```

Make sure the MQTT node shows:

```text
connected
```

---

## 3. Start Flask

Open another terminal.

Activate the virtual environment:

```powershell
.\venv\Scripts\Activate.ps1
```

Run:

```powershell
python app.py
```

Open the website:

```text
http://127.0.0.1:5000
```
